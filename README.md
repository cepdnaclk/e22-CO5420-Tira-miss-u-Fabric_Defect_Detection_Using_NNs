# Overview

Fabric Defect Detection Using the AITEX Image Database
Textile quality control often depends on manual visual inspection, which can be slow, subjective, and affected by operator fatigue. This competition asks you to automate part of that process by classifying high-resolution fabric images as defective or defect-free.
